Step 3 — If Mac blocks the app

This is normal the first time. Follow these steps:

3
Go to System Settings
Click the Apple menu (top-left corner) → System Settings
4
Privacy & Security

Click Privacy & Security in the left sidebar.

5
Scroll all the way down

At the bottom of the page, look for a message like:

"Open-VenusP.command was blocked because it is from an unidentified developer"

Click the button Open Anyway next to that message.

Confirm by clicking Open Anyway one more time.

6
Try again

Go back to the folder and double-click Open-VenusP.command (or right-click → Open).

Still stuck? Ask someone to open Terminal in that folder and run:
xattr -cr . && chmod +x Open-VenusP.command && ./Open-VenusP.command
